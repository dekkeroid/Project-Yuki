1. Tool Execution & Safety Architecture

        

          
    
            
  • Registration: Tools are declared in app/tools/definitions.py as OpenAI schemas and dispatched in app/agent/executor.py.
    • 
            
  • Safety Preflight: app/tools/safety.py::authorize_tool_call checks path safety, confirmation gates for destructive actions in assistant mode, and sandboxing.
    • 
            
  • Dual Dispatch: Forwarded via MCP stdio (app/mcp_server.py) or executed locally on worker threads (asyncio.to_thread).
    • 
            
  • Logging: Execution duration, arguments, and outcomes are journaled into backend/tool_runs.jsonl.
    • 
          

        

      


      

        
2. Kokoro Neural Speech Synthesis Pipeline

        

          
    
            
  • Model Weights: Kokoro ONNX uses a unified FP16 ONNX model (kokoro-v1.0.fp16.onnx) and a binary voice matrix (voices-v1.0.bin).
    • 
            
  • Zero-Reload Switching: Switching between 19+ voices loads only the target voice vector in memory; the ONNX graph stays resident in RAM/VRAM without re-initialization.
    • 
            
  • Speed Scaling: Speed factor (0.5x to 2.0x) is calculated into the phoneme duration model without pitch changes.
    • 
            
  • Streaming: Generates pure 24,000 Hz 16-bit PCM WAV audio delivered in RAM directly via GET /api/tts.
    • 
            
  • Expressive Interjections (Direct IPA Injection): Intercepts non-dictionary vocal groans and conversational fillers (Mmrgh, Hmmmm, Pfft, Shhh, Fufufu, E-eh?!, Mm-hmm) and translates them into native Kokoro IPA phonemes, eliminating espeak letter-spelling artifacts.
    • 
          

        

      


      

        
3. Faster-Whisper & Dual-Stage VAD Pipeline

        

          
    
            
  • Stage 1 (Frontend): Browser Web Audio API analyzes microphone RMS audio level and applies Silero WebAssembly neural confidence filter before capturing.
    • 
            
  • Stage 2 (In-Memory Transit): Audio blobs are streamed to POST /api/speech/transcribe or over WebSocket streams.
    • 
            
  • Stage 3 (PyTorch Silero VAD): Backend Silero VAD purges background noise and isolates valid speech timestamps.
    • 
            
  • Stage 4 (CTranslate2 Faster-Whisper): Low-latency beam_size=1 greedy decoding transcribes speech on CUDA/CPU with anti-hallucination post-filtering.
