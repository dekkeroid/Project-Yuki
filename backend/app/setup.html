Hardware Recommendation: Cloud APIs vs. Local LLMs Recommended
For average PC setups without a high-end dedicated GPU, we strongly recommend using cloud APIs instead of local LLMs. Running local models (via LM Studio or Ollama) consumes significant VRAM and CPU cycles, which can cause avatar rendering stutters and sluggish voice response times.

Top Free/Budget Choice: Gemini Flash Lite via Google AI Studio. It offers free-tier API access, near-instant generation speed, generous rate limits, and excellent tool-calling accuracy for desktop actions. You can paste your API key directly in Yuki's Settings > Models after launch.
Setting Up Your LLM & AI Brain: You can configure your local models (LM Studio / Ollama) or cloud API keys directly inside Yuki's Settings Dashboard > Models & Brain tab at any time after launch.
Prompt Strategies & Execution Modes Architecture
Yuki gives you total control over how conversation and tools are routed. Choose the strategy that fits your hardware best:
Dynamic Mixed Prompts Default & Recommended
Automatically routes casual banter with lightweight, fast prompts, and seamlessly injects tool schemas only when system tasks, screen vision, or web searches are required.
Simple Prompts Only Lean & Fastest
Ideal for lightweight models (1B–3B) or pure conversational chat. Disables tool overhead for lowest latency and instant voice responsiveness.
Complex Prompts Only Full Autonomous
Forces full autonomous system prompts on every turn. Best suited for cloud frontier models (Gemini 2.5, GPT-4o, Claude) executing multi-step desktop tasks.
Dual vs. Single Endpoint Strategy Speed & Cost Optimizer
Under Settings > Endpoint Strategy, you can configure:
Single Endpoint
One unified model handles both casual conversation and complex desktop tool execution.
Dual Endpoint Strategy
Use a fast, free local model (e.g. Qwen 2.5 7B, Llama 3.2 3B) for instant chatter, and automatically call a frontier cloud API only when system tools or coding tasks are triggered.
